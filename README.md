\# Used Bike Prices – Feature Engineering \& EDA



\## Project Overview



This project analyzes used bike prices using Python, Pandas, NumPy, Matplotlib, and Seaborn.



The project focuses on data cleaning, feature engineering, exploratory data analysis, visualization, and correlation analysis.



\## Features



\- Data cleaning and preprocessing

\- Missing value handling

\- Duplicate detection

\- Numerical feature extraction

\- Feature engineering

\- Exploratory Data Analysis

\- Correlation analysis

\- Data visualization



\## Feature Engineering



The following features were created:



\- Bike\_Age

\- Age\_Category

\- Price\_Per\_KM

\- Usage\_Category

\- Power\_Category



\## Technologies Used



\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn

\- Jupyter Notebook



\## Project Files



\- `Used\_Bike\_Prices.ipynb` – Complete analysis

\- `used\_bike\_prices\_feature\_engineered.csv` – Feature-engineered dataset
